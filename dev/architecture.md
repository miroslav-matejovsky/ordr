# Core Architecture

ORDR separates knowledge, relationships, and views.

## Knowledge

The source of truth.

Contains opportunities, decisions, evidence, reviews and other domain records.

## Graph

The relationship model.

Contains explicit relationships between domain concepts, including:

- supports
- blocks
- enables
- invalidates
- relates
- ranks higher than

## Projections

Generated views derived from knowledge and graph data.

Examples:

- Strategic Opportunity Matrix
- Relative Rankings
- Decision Readiness Board
- Review Summaries
- Wardley Maps
